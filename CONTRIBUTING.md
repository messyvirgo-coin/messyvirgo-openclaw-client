# Contributing

This repo is a **Messy Virgo** wrapper around [OpenClaw](https://github.com/openclaw/openclaw). PRs are welcome; maintainers decide what merges.

## Rules

- Follow [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).
- No secrets, tokens, private URLs, or personal data in commits or PRs.
- Keep changes focused and portable (Linux + macOS bash where scripts apply).
- Update docs when user-facing behavior changes.

## PRs

- State the problem and what you changed.
- Note how you tested (OS, Docker version if relevant).
